HDRezka для Lampa

Просмотр из карточек фильмов и сериалов через rezka.fi. Версия 0.2.3.

  1. Добавьте постоянную ссылку на плагин в расширения Lampa. Если раньше установлен rezka-fi-auth.js или ссылка с хешем коммита, один раз замените её адрес. Полностью перезапустите приложение. Для следующих обновлений менять ссылку не нужно.
  2. Для Premium откройте Настройки → Rezka.fi: вход, укажите email/логин и выполните вход. В первой строке раздела отображается версия загруженного плагина. Пароль вводится только в Lampa на вашем устройстве.
  3. Откройте карточку фильма → Смотреть → HDRezka. В старом интерфейсе доступна отдельная кнопка HDRezka.
  4. Выберите найденный фильм, озвучку и качество. Доступные качества идут от максимального к минимальному: 4K → 2K → 1080p Ultra → 1080p → 720p и ниже. Для сериалов также выберите сезон и серию. Другие форматы и ссылки доступны при удержании OK на качестве.

Видео открывается в плеере Lampa. Следующая серия выбирается вручную. Эта страница не принимает данные аккаунта.

Локальные сценарии проверены с тестовыми ответами. Реальный вход и просмотр на LG ещё требуют проверки: доступ зависит от rezka.fi, CORS и cookies в вашей сборке Lampa.
