# HDRezka для Lampa на LG

Готовое расширение для просмотра из карточек фильмов и сериалов через rezka.fi.

## Установка и обновление

Добавьте в **Настройки → Расширения** постоянный адрес:

```text
https://hdrzk.glossyorbit10.chatgpt.site/r.js
или
https://cdn.jsdelivr.net/gh/vppower-wqr/hdrzk@main/docs/rezka-fi.js
```

При обновлении адрес остаётся прежним. Оставьте только одну установленную копию расширения и полностью перезапустите Lampa. Точная версия загруженного файла отображается в **Настройки → Rezka.fi: вход → Версия плагина**. Обновление может задерживаться из-за кеша CDN или приложения.

## Просмотр

1. Для Premium откройте **Настройки → Rezka.fi: вход**, укажите логин и выполните вход. Пароль вводится в Lampa на вашем устройстве.
2. В карточке фильма или сериала нажмите **Смотреть → HDRezka**. В старом интерфейсе доступна отдельная кнопка HDRezka.
3. Откроется страница просмотра. Для фильма выберите строку с названием, для сериала — серию. Фильтры сверху меняют озвучку и сезон; предыдущий выбор запоминается. Если поиск неоднозначен, варианты отображаются на этой же странице.
4. Выберите качество: доступные варианты расположены от максимального к минимальному. Дополнительные форматы и запасные ссылки доступны при удержании OK на качестве.

Длинные списки прокручиваются стрелками пульта. Превью, названия и другие данные серий показываются при наличии в каталоге Lampa. Страница сохраняет прогресс просмотра. Во встроенном плеере следующая серия запускается автоматически с той же озвучкой и предпочитаемым качеством, если они доступны. Внешние плееры могут не поддерживать автоматическое продолжение.

## Аккаунт

У каждого пользователя свой аккаунт и сессия rezka.fi. Пароль используется для одного входа и не записывается в настройки плагина. Поиск, вход и запросы видео идут напрямую на rezka.fi; видео загружается с адресов, возвращённых сайтом.

Работа зависит от доступности сайта, cookies и установленной сборки Lampa. При сетевой ошибке или ограничении доступа плагин сообщает об ошибке.
