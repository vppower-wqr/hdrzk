# HDRezka для Lampa на LG

Версия **0.2.2** добавляет просмотр из карточек фильмов и сериалов Lampa через `https://rezka.fi`: поиск, выбор фильма, озвучки и качества, для сериалов — сезона и серии. Видео открывается в плеере Lampa. В настройках остаются вход в аккаунт, проверка сессии и выход.

## Установка или обновление

Добавьте в **Настройки → Расширения** постоянный адрес:

```text
https://cdn.jsdelivr.net/gh/vppower-wqr/hdrzk@main/docs/rezka-fi.js
```

Все следующие версии публикуются по этому же адресу. Менять ссылку при каждом обновлении не нужно: обновляется содержимое файла `docs/rezka-fi.js` в ветке `main`.

Если ранее установлена ссылка с хешем коммита или файл `rezka-fi-auth.js`, один раз замените её на постоянный адрес выше. Оставьте только одну версию этого расширения и полностью перезапустите Lampa. Email и сессия используют прежние настройки и cookies. Старый файл в репозитории также обновляется для совместимости.

Обновления могут задерживаться из-за кеша CDN или приложения. После выхода новой версии перезапустите Lampa; если загрузилась старая версия, может потребоваться очистка кеша приложения.

Для размещения через GitHub Pages можно самостоятельно включить **Settings → Pages → Deploy from a branch → main → /docs**. Основная ссылка выше работает через jsDelivr и не требует Pages.

## Как смотреть

1. Для Premium откройте **Настройки → Rezka.fi: вход**, заполните email/логин, выберите **Войти на rezka.fi**, введите пароль и подтвердите **Войти**. Затем проверьте сессию в том же разделе.
2. Откройте карточку фильма или сериала в каталоге Lampa.
3. Нажмите **Смотреть → HDRezka**. В старом интерфейсе кнопка **HDRezka** отображается прямо на карточке. Также доступен запуск из меню карточки при долгом нажатии OK.
4. Выберите подходящий результат поиска по названию и году, затем озвучку. Для сериала выберите сезон и серию.
5. Выберите качество. Список идёт от максимального к минимальному: **4K → 2K → 1080p Ultra → 1080p → 720p → 480p → 360p**, только из доступных вариантов. На каждое качество показывается один пункт; если доступен HLS, он выбран первым. Откроется плеер Lampa. Для выбора MP4 или другой ссылки удерживайте OK на нужном качестве: появится список доступных вариантов.

При закрытии плеера возвращается меню качества. Кнопка «Назад» возвращает к сериям, озвучкам и найденным фильмам. Переход к следующей серии выполняется вручную через меню серий. Во время запроса можно выбрать «Отмена» или нажать «Назад».

Если по названию из карточки ничего не найдено, плагин пробует оригинальное название. Совпадение названия не гарантирует совпадение фильма, поэтому выбор результата остаётся за пользователем.

## Аккаунт и подключение

Все запросы поиска, входа, страниц и ссылок на видео идут напрямую на `https://rezka.fi` с `withCredentials: true`. Видео и субтитры проигрываются с адресов CDN, которые вернул сайт. Cookies хранит браузерное окружение самой Lampa. Email хранится в настройках устройства; пароль плагин использует для одного входа и не записывает в настройки. Не добавляйте пароль, cookies или данные аккаунта в GitHub и не отправляйте их разработчику.

После запроса входа плагин отдельно проверяет главную страницу с cookies. Premium подтверждается по соответствующему классу `body`, обычный вход — по ссылке выхода. Один ответ HTTP 200 не считается успешным входом.

Это самостоятельный источник **HDRezka**. Плагин не меняет настройки BwaRC и не добавляется в его внутренний список балансеров. BwaRC и другие расширения могут оставаться установленными.

## Ограничения и статус проверки

Работа зависит от доступа к rezka.fi, правил CORS и политики сторонних cookies в установленной сборке Lampa. При контрольных GET/OPTIONS-запросах с Origin `null` разрешающие CORS заголовки не обнаружены. Обычный браузер может блокировать прямые запросы; наличие Premium этого ограничения не снимает. Вход в отдельном браузере LG сам по себе не означает, что сессия доступна приложению Lampa.

При ошибке CORS, сети, защите сайта или неизвестном формате плагин сообщает об ошибке. Он не передаёт пароль на сторонние прокси и не обходит проверки доступа. Ссылки на видео имеют ограниченный срок действия; если старая ссылка перестала работать, заново выберите фильм/серию.

**Проверено:** локальные сценарии с искусственными ответами, регистрация источника и размещение кнопки по исходникам Lampa. **Не проверено:** реальный вход, Premium-видео и воспроизведение на вашем LG. Установка JavaScript сама по себе не подтверждает доступ к сайту или проигрывание видео.

[Правила HDRezka](https://rezka.fi/rules/) запрещают Lampa и её плагины даже с Premium и допускают ограничение аккаунта без предупреждения.

## Разработка

Исходник — `src/rezka-fi.js`. Команда сборки создаёт одинаковые файлы `docs/rezka-fi.js` и `docs/rezka-fi-auth.js`. Код плагина написан без сборщика и современного синтаксиса JavaScript для совместимости со старыми webOS.

```bash
npm install --ignore-scripts
npm test
node --check docs/rezka-fi.js
```

Перед тестами автоматически выполняется сборка. Тесты не обращаются к реальному сервису: проверяются вход/выход, передача cookies, отмена запросов, поиск, выбор фильма/озвучки/серии/качества, отсутствие дублей качества при нескольких ссылках, доступность запасных вариантов, декодирование ссылок, запуск плеера, ошибки сайта и повторная загрузка расширения.

При публикации сохраняйте постоянный URL `https://cdn.jsdelivr.net/gh/vppower-wqr/hdrzk@main/docs/rezka-fi.js`. Обновляйте существующий файл в `main`, без замены установочной ссылки на номер версии или хеш коммита. После публикации запросите очистку кеша через [инструмент jsDelivr](https://www.jsdelivr.com/tools/purge) и проверьте, что постоянный адрес отдаёт тот же JavaScript, который прошёл проверки. Очистка CDN не удаляет локальный кеш Lampa.

Использованы интерфейсы из [исходников Lampa](https://github.com/yumata/lampa-source). Реализация написана отдельно; исходный Online Mod не включён в пакет. Лицензия этого проекта — MIT.
