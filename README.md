# Rezka.fi: вход — плагин для Lampa на LG

Версия 0.1.0. **Только авторизация на `https://rezka.fi`**: email/логин, ввод пароля, вход, проверка сессии и выход. Каталог, поиск фильмов, плеер и другие балансеры сюда не входят.

Порядок запросов изучен по [online_mod.js](https://nb557.github.io/plugins/online_mod.js), версия файла от 10.10.2026, функции `rezka2Login` и `rezka2Logout`. Реализация написана отдельно; исходный Online Mod не включён в пакет.

Плагин использует прямые HTTPS-запросы с `withCredentials: true`. Cookies сохраняет браузерное окружение самой Lampa, если оно разрешает такую работу. Плагин не пытается читать `Set-Cookie` или `document.cookie` чужого домена, не использует чужие прокси и не выполняет запросы к `hdrezka.website`.

## Установка через GitHub Pages

1. Исходный код: [vppower-wqr/hdrzk](https://github.com/vppower-wqr/hdrzk). Для публикации файла включите Pages, как описано ниже.
2. В **Settings → Pages** выберите **Deploy from a branch → main → /docs**, нажмите Save.
3. После публикации добавьте в расширения Lampa ссылку вида:

   ```text
   https://vppower-wqr.github.io/hdrzk/rezka-fi-auth.js
   ```

4. Перезапустите Lampa.
5. Откройте **Настройки → Rezka.fi: вход**, укажите email или логин.
6. Нажмите **Войти на rezka.fi**, введите пароль и затем выберите **Войти**. Пароль не записывается в настройки этим плагином.
7. При необходимости используйте **Проверить сессию rezka.fi**.

Если у вашего репозитория уже есть другой сайт Pages, используйте отдельный репозиторий, чтобы не менять публикацию существующего сайта.

Пароль, cookies и данные вашего аккаунта не нужно добавлять в GitHub или отправлять разработчику. В исходном файле их нет. Email хранится в настройках на вашем устройстве; пароль используется для одного входа. Сессионные cookies могут сохраняться браузером между перезапусками.

## Что считается успешным входом

После ответа на запрос входа плагин отдельно загружает главную страницу с cookies. Он подтверждает Premium только при наличии соответствующего класса у `body`, а обычный вход — при наличии ссылки выхода. Страница с формой входа означает, что сессия не подтверждена. Неизвестная страница или HTTP 200 сами по себе успехом не считаются.

## Совместимость с BwaRC и Online Mod

Этот файл **не добавляет источник в список BwaRC и не изменяет его настройки**. Вход будет полезен другому плагину только если тот обращается к тому же `https://rezka.fi` напрямую, в том же браузерном окружении и с включённой передачей cookies.

Для Online Mod в его настройках HDrezka нужно выбрать зеркало `https://rezka.fi`; запросы через отдельный сервер/прокси могут использовать другую сессию. Сам Online Mod уже содержит собственные кнопки входа. Совместимость с конкретной сборкой BwaRC не подтверждена: её исходник получить не удалось.

## Ограничения LG webOS

Наличие прямого входа в Online Mod не гарантирует работу во всех LG/Lampa. На разных сборках запрос может блокироваться правилами CORS или политикой сторонних cookies. В контрольных GET/OPTIONS-запросах с Origin `null` заголовки, разрешающие CORS, не были обнаружены; это существенное ограничение для обычного браузерного режима.

Если появляется сообщение о CORS/cookies/сети, плагин не считает вход успешным и не отправляет пароль на другой прокси. Возможность такого входа нужно проверить в установленной у вас сборке Lampa. Вход на rezka.fi в отдельном браузере LG сам по себе не означает, что эта сессия доступна приложению Lampa.

Статус: локальные тесты с искусственными ответами выполнены; реальный вход в аккаунт и работа на вашем LG ещё не проверены. Веб-форма rezka.fi на момент проверки содержит поля `login_name`, `login_password` и запрос `/ajax/login/`.

[Правила HDRezka](https://rezka.fi/rules/) запрещают Lampa и её плагины даже с Premium и допускают ограничение аккаунта без предупреждения. Эта версия не обходит защиту доступа.

## Проверки

```bash
npm install --ignore-scripts
npm test
node --check docs/rezka-fi-auth.js
```

Тесты не обращаются к реальному сервису. Проверяются привязка к домену, передача cookies, отсутствие записи пароля в настройки, отмена ввода, отказ сервиса, проверка сессии после входа, проверка выхода и защита от повторной регистрации.
